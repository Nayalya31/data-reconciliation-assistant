# Личный аналитик данных

FastAPI-приложение на Jinja2 и HTMX: чат с OpenAI, загрузка и анализ таблиц и изображений, preview, графики, DOCX и Markdown. Дополнительный сценарий выполняет бухгалтерскую сверку взаиморасчётов с контрагентом полностью на сервере.

## Сверка взаиморасчётов

- две выгрузки XLSX/CSV за один период по одному контрагенту;
- ручное сопоставление колонок даты, документа, операции и суммы;
- зеркальное сравнение с денежной точностью `Decimal("0.01")`;
- начальное/конечное сальдо, расхождение операций и необъяснённый остаток;
- отдельные категории: нет у одной стороны, сумма отличается, дубль, частичная оплата, неоднозначное совпадение;
- Excel с листами `Итоги`, `Расхождения`, `Ручная проверка`;
- серверная история сверок, проверка владельца и защищённое скачивание;
- публичное демо только на синтетических данных: `/reconciliation/demo`.

Исходные бухгалтерские выгрузки не отправляются в OpenAI. Модели может передаваться только обезличенная рассчитанная сводка.

## Локальный запуск

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Перед запуском замените `APP_USERNAME`, `APP_PASSWORD`, `SESSION_SECRET` и при необходимости `OPENAI_API_KEY`. Откройте `http://localhost:8000`.

## Демо с известным результатом

Файлы `examples/reconciliation_ours.csv` и `examples/reconciliation_counterparty.csv` дают:

- 2 однозначно подтверждённые операции;
- расхождение операций и конечного сальдо `450.00`;
- необъяснённый остаток `0.00`;
- примеры расхождения суммы, отсутствующей операции, дубля и частичной оплаты.

## Docker

```bash
cp .env.example .env
docker compose up --build -d
```

Каталог `./storage` монтируется целиком, поэтому SQLite-история, входные файлы и отчёты сохраняются после перезапуска контейнера. Миграции из `migrations/` применяются при старте.

## Хранение и безопасность

По умолчанию история находится в `storage/app.db`. Рабочие выгрузки — в `storage/reconciliation_inputs`, результаты — в `storage/outputs/reconciliations`. Все эти пути исключены из Git и Docker-контекста. Для production включите `COOKIE_SECURE=true`, задайте уникальный `SESSION_SECRET` и публикуйте сервис только через HTTPS reverse proxy.
